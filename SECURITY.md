# Security Policy

## Supported Versions

Only the latest release receives security fixes.

## Reporting a Vulnerability

Please report vulnerabilities privately, through [GitHub's private vulnerability reporting](https://github.com/coipond/fisherman/security/advisories/new), not in public issues.

You can expect a reply within 2 working days. We will confirm the report, assess it, keep you updated, and credit you in the release notes unless you prefer otherwise.

## Detection bypasses

A way to make Fisherman miss content it should flag is a vulnerability too. Please report it privately with a minimal example, so the fix can ship before the technique is public.
